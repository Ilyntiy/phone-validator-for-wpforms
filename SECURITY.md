# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Write privately on Telegram: [@advertsales](https://t.me/advertsales), or use **Report a vulnerability** on the Security tab of this repository. Describe what you found, how to reproduce it and which version is affected. You will get an answer as soon as possible, and the fix is released before the details are made public.
